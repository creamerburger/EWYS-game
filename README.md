# BOMB QUIZ · 폭탄 퀴즈

오프라인 주일학교 행사용 한영 병기 팀 대항 퀴즈 게임입니다.

## 실행

```powershell
cd C:\Users\user\Documents\영어캠프\bomb-quiz
npm install
npm run dev
```

브라우저에서 출력된 로컬 주소를 엽니다. 인터넷 없이 실행할 수 있도록 이미지, 폰트, 네 곡의 오디오를 프로젝트에 포함했습니다. 배포용 파일은 `npm run build`로 `dist/`에 생성합니다.

## 기본 게임

- 4팀, 성경 문제 25개와 찬양 제목 문제 4개가 준비되어 있습니다.
- 문제와 메뉴의 한국어/영어를 동시에 표시합니다.
- 성경 문제는 주관식에서 객관식으로 바꿀 수 있으며 객관식 정답은 원래 배점의 20%를 10점 단위로 반올림합니다. 객관식 정답도 설정된 보너스 확률을 적용받습니다.
- 찬양 문제는 주관식만 사용합니다. 30초 타이머가 표시되며, 제목을 모르면 한 소절 부르기 찬스를 사용합니다. 네 곡의 정답과 허용 답안은 문제 데이터에 저장되어 있습니다. 진행자는 `정답 확인·공개`로 제목을 확인하고 `정답!` 또는 `오답 / 다음 팀`을 누릅니다. 오답이면 점수 없이 다음 팀 차례의 문제판으로 돌아갑니다. 문제는 사용 처리되지 않아 다시 선택할 수 있습니다.
- 정답 기본 점수를 먼저 지급하고 보너스 상자를 엽니다. 기본 설정은 정답마다 50% 확률로 보너스가 나타나며, 상자 9개의 결과를 미리 가중치에 따라 섞습니다. 보너스 확률과 추첨 방식은 설정에서 바꿀 수 있습니다. 진행 중에도 사회자 패널에서 보너스 확률을 0·25·50·75·100%로 조정할 수 있습니다. 폭탄과 꽝은 이번 상자 보너스 0점이며, 누적 점수는 깎지 않습니다. 점수 교환, 점수 2배, 추가 상자 등은 남아 있습니다. 방패가 있으면 폭탄에서 +100점입니다.
- 모든 버튼에 짧은 뾱 효과음이 나고 문제 타이머는 1초마다 째깍 소리가 납니다. 마지막 10초는 더 크게 울립니다. 설정이나 사회자 패널에서 사운드를 끌 수 있습니다. 문제 화면의 `문제판으로`는 문제를 사용 처리하지 않고 돌아갑니다. 게임은 localStorage에 자동 저장됩니다. 업로드한 큰 오디오는 IndexedDB에 저장합니다.
- 사회자 패널에서 점수 수정, 차례 변경, 되돌리기, 문제 재활성화, 결과 지정, JSON 또는 오디오 포함 ZIP 백업/복원을 할 수 있습니다.

## 게임 크레딧

찬양 제목, 아티스트, 원본 영상 링크는 문제 중에 노출되지 않습니다. 게임이 끝난 뒤 최종 결과 화면의 접힌 `게임 크레딧 · 찬양 출처`를 열면 확인할 수 있습니다. 출처 표기는 음원 사용 허가를 대신하지 않습니다.

## 구조

```text
src/App.tsx          화면, 튜토리얼, 설정, 문제 편집기
src/engine.ts        점수와 이벤트 규칙
src/store.ts         상태 머신, 행동 기록, 자동 저장
src/data.ts          한영 문제은행과 기존 영문 JSON 변환
src/audio.ts         IndexedDB 오디오 저장과 백업
src/sound.ts         Web Audio 효과음
src/*.test.ts        핵심 규칙과 저장 테스트
public/assets/       생성 이미지, SVG, 찬양 MP3
scripts/             에셋 생성 및 브라우저 검증 스크립트
```

## 검증

```powershell
npm test
npm run build
```

20개 자동 테스트가 팀 생성, 객관식 점수, 폭탄과 방패, 점수 교환, 음수 방지, 중복 지급 방지, 관리자 결과 변경, 새로고침 복원, 종료/재시작, IndexedDB 오디오, JSON 복원, 한 소절 찬스를 검사합니다. 헤드리스 Chrome에서 성경 문제, 찬양 문제, 오디오 포함 ZIP 백업과 복원의 실제 화면 흐름도 확인했습니다. 개발 서버를 실행한 상태에서 `node scripts/browser-qa.mjs`, `node scripts/song-qa.mjs`, `node scripts/backup-qa.mjs`, `node scripts/timer-board-qa.mjs`, `node scripts/credits-qa.mjs`로 재검증할 수 있습니다.

## 디자인 에셋

`stage.png`, `chest.png`, `chest-open.png`, `trophy.png`는 내장 이미지 생성 도구로 제작했습니다. 프롬프트 방향은 각각 보라/남색의 금빛 게임쇼 무대, 금테두리 보라 보물상자, 금화가 보이는 열린 상자, 보석이 있는 금색 우승 트로피입니다. 폭탄·폭발·코인·이벤트 카드·축하 배경은 `scripts/make-assets.mjs`에서 SVG로 제작합니다. 모든 핵심 에셋은 로컬 파일입니다.

## 제한사항

- 사회자가 정답과 한 소절 부르기의 성공 여부를 직접 판정합니다.
- 일반 JSON 백업에는 게임 데이터가 들어갑니다. 오디오 포함 ZIP 백업에는 게임 데이터, 문제은행, 기본 네 곡의 미리듣기와 전체 음원, IndexedDB에 업로드한 음원이 함께 들어갑니다. ZIP 복원은 동일한 앱 버전의 로컬 정적 에셋을 사용합니다.
- 브라우저별 localStorage/IndexedDB 용량 제한이 있으므로 행사 전에 오디오 포함 ZIP 백업을 내려받는 것이 좋습니다.
